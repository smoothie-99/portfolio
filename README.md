# 강한솔 백엔드 개발자 포트폴리오

Java와 Spring Boot를 중심으로 수행한 프로젝트 경험을 백엔드 채용 관점에서 정리한 정적 웹 포트폴리오입니다.

## 구성 원칙

- 기술 나열보다 `문제 → 역할 → 구현 → 검증` 흐름을 우선합니다.
- 대표 백엔드 프로젝트를 먼저 배치하고, AI 경험은 서비스 연계 관점으로 설명합니다.
- 프론트엔드 경험은 API 명세·검증·협업 역량을 보여주는 근거로 구분합니다.
- 확인되지 않은 수치나 담당 범위는 추가하지 않습니다.

## 주요 내용

- **내 요리를 부탁해**: JWT 인증, JPA·PostgreSQL 데이터 저장, 트랜잭션, Docker·AWS 배포
- **JipChak**: Redis QR 세션, 녹화 메타데이터, AI 추론 결과와 백엔드 서비스 연계
- **HearBe**: API 명세 협의, Postman 검증, 누락 응답 데이터 발견과 Response·DTO 개선 협업
- **Experience**: 제조 장비 설계·BOM·부품 발주 경험을 요구사항·구조·흐름 관리 역량으로 연결

## 확인 방법

별도의 설치 과정 없이 `index.html`을 열어 확인할 수 있습니다. 로컬 웹 서버를 사용하면 모바일 메뉴와 프로젝트 필터를 포함한 전체 동작을 확인할 수 있습니다.
